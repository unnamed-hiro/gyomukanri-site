機能の一覧

業務管理（GyomuKanri）／運営: unnamed　行方 浩太
2026年10月28日の時点で入っている機能です。

業務管理（GyomuKanri）は、個人事業主が案件・支出・予定・請求書をひとつにまとめて管理するためのアプリです。 iPhone / iPhone Duo / iPad / Mac で同じアプリが動き、データは利用者ごとに分かれたサーバー（Supabase）に置くので、 どの端末からも同じ中身を見られます。現在は運営者本人が自分の業務のために使っていて、一般には配布していません。

動くのは iOS 17 以上・macOS 15 以上です。端末の中で動く AI の機能（メッセージからの候補・録音の文字起こし）だけは iOS 26 / macOS 26 以上の端末が要ります。情報の扱いは プライバシーポリシー に書いてあります。

案件と取引先

  • 取引先（クライアント）ごとに色を決めて登録。カレンダーの帯はその取引先の色で出ます
  • 案件は 見積提出 → 進行中 → 納品済 → 請求済 → 入金済 → 完了 のステータス、受注額（税別）、納期、月額（継続）の区別を持ちます
  • ココナラ経由の案件は、販売手数料（22%）を引いた受取額で受注額・粗利・実効時給を数え、「入金済」にした瞬間に入金を1件自動で記録します
  • 取引先の詳細は1画面に、数字のまとめ・案件・請求書・見積書・入金・これからの予定・タスク・メッセージ・Web チャット・アプリの利用者とのつながりを並べます
  • ホームには 受注額・入金済・未回収 の3枚、今日の予定、今日と期限切れのタスク、計測中のタイマー、自動で作った請求書の下書きを出します

予定（カレンダー）

  • 月・週・日・リスト・タスク の5つの表示。日をまたぐ予定は帯（取引先の色）、1日だけの予定は点（種類の色）。日本の祝日も出ます
  • iPad・Mac や iPhone Duo を開いたときは、左にカレンダー／右にその日の詳細、または名前の札を入れたカレンダーだけを画面いっぱいに出す形を選べます。帯や札の見方は「表示の見方」から開けます
  • 終日・時刻つき・場所・メモ・繰り返し（毎週・毎月など。削除は「この回だけ／これ以降／すべて」）
  • 1つの予定に案件を10件までひも付けられます（取引先をまたいでもよい）
  • 案件の納期・タスクの期限・請求書の支払期限を、予定とは別の線種（破線・中空の点）でカレンダーに重ねて出します
  • プライベートの予定（仕事ではない予定。取引先・案件を持たない）と、共有の URL に出さない「隠す」の印
  • シークレットの予定。端末の鍵（Face ID・Touch ID・パスコード）を開けたときだけ画面に出ます。ウィジェット・Siri・端末のカレンダー・共有の URL には出ず、通知は中身を伏せて鳴ります
  • 予定から1押しで「実績にする」（稼働の記録）と「交通費を記録」（支出）
  • 週・日の表示では、予定を指でドラッグして時間を動かせます
  • 端末のカレンダー（Apple のカレンダーアプリ）への書き出し。仕事とプライベートで別のカレンダーを選べます
  • 予定の共有。URL を1本渡すと、アプリを持たない人のカレンダー（Apple・Google）やブラウザに、予定の件名と時間だけが出ます。家族用・外注先用など何本でも作れ、止めるのは1押しです
  • 通知は N 分前・前日の朝に加えて、好きな日時を5つまで指定できます

タスク

  • 題名・期限（日付だけ／時刻つき）・優先度・メモ。案件か取引先に結び付けられます（結ばなくてもよい）
  • 期限切れ／今日／これから／期限なし／完了 の節に自動で並び、ホームには「今日と期限切れ」を出します
  • 通知は前日の朝と、時刻つきなら1時間前。好きな日時の通知も5つまで
  • メッセージや録音から AI が拾った「候補」（依頼・約束・予定）は、押すと中身の入ったエディタが開き、保存したときだけタスクや予定になります

請求書・見積書・入金

  • インボイス制度の記載に沿った請求書。消費税は明細ごとに税率を持ち、端数処理は1枚につき税率ごとに1回。軽減税率（8%）の明細には※印と注記、発行者の登録番号を刷ります
  • 源泉徴収（100万円まで 10.21%、超えた分 20.42%）の計算と記載。取引先ごとの既定を請求書ごとに変えられます
  • 1枚に複数の案件をまとめられ、案件ごとの請求額・入金・未回収を自動で振り分けます。金額を持たないテキストの行、16行以上のときのページ割りにも対応
  • 紙面は freee請求書の標準レイアウトに寄せた A4。画面でそのまま見られ、PDF にして共有できます
  • 送り方は メールで送る・PDF を共有する・freee で送る・送付済にする の4つ。iOS のメールから送ると自動で「送付済」になります
  • 予約送信。日時を決めておくと、その時刻に利用者自身の Gmail からサーバーが送ります（アプリを閉じていても送られ、控えが自分にも届きます）。前日・1時間前・時刻ちょうどに通知
  • 月額の案件は、決めた日に請求書の下書きを毎月自動で作ります（送るのは人）
  • 見積書。請求書と同じ紙面で、見積番号・見積日・有効期限を持ち、「請求書にする」で明細ごと写せます
  • 見積書は文章からも起こせます。Claude などに書かせた明細（表・JSON・箇条書き）を貼り付ける、macOS の「サービス」から送る、リンクで開く、の3つの入口。読めた結果を人が確かめてから作ります
  • 入金は 着金した額・差し引かれた源泉徴収・振込手数料 を分けて記録し、請求書に消し込みます。残高・未回収は毎回数え直すので、二重に数えません

支出と経費

  • 経費の科目は自分で足せます（青色申告決算書の科目に対応。初期は23科目）。科目を名前で変えても過去の集計は崩れません
  • 家事按分。科目ごとの既定の率と、支出ごとの率（1〜100%）を持ち、経費に数えるのは按分後の金額
  • 事業主貸。事業の口座・カードで払った私用の支払いを記録し、経費には数えません
  • 領収書の取り込み。写真を撮る／選ぶと、画像の傾きを直して 日付・金額・支払先 を読み取り、支出の下書きにします（読めなかった項目は空のまま）。画像は領収書として保存します
  • 月ごとの一覧、日ごとの合計、科目別・案件別の内訳。案件ごとの原価と粗利

稼働時間

  • 開始と終了を記録し、案件ごとに合計。受注額 ÷ 稼働 で実効時給を出します（月額の案件では出しません）
  • タイマー。1人に1本で、Mac で始めて iPhone で止めることもできます。iOS ではロック画面と Dynamic Island に経過が出ます（Live Activity）
  • 「大きく表示」で時計を画面いっぱいに。iPhone Duo を半分たたんで机に置くと、上に時計・下にボタンが来ます

メッセージ

  • LINE 公式アカウント・Chatwork・メール（Gmail）・Web チャット・アプリの利用者どうし・自分のメモ の6つの経路を、取引先ごとに1本の会話にまとめて時間順に並べます
  • 相手は「取引先」と「個人」（家族・友人）に分かれます。個人の相手は「シークレット」にでき、端末の鍵を開けたときだけ一覧と検索に出ます
  • LINE のような吹き出しの会話画面。相手が読んだ「既読」は、両端がこの仕組みである Web チャットとアプリの利用者どうしだけに出します。LINE の相手には、こちらが読んだ既読を付けます
  • 添付。LINE のスタンプ・画像・動画を会話の中で見られ、LINE・メール・Web チャット・アプリの利用者へ画像・動画・ファイルを送れます（カメラで撮ってそのまま送るも）。写真は位置情報を落として送ります
  • Web チャット。アプリを持たない相手に URL と6桁の合言葉を渡すと、ブラウザのチャット画面でやり取りでき、画像・ファイルも渡し合えます。URL はいつでも止められます
  • アプリの利用者どうし。招待の URL か8文字のコードでつながり、LINE などにつながなくてもやり取りできます
  • 未読の数、相手の無視・ブロック、やり取りの削除、取引先への結び付けと付け替え、相手の名前の変更
  • 吹き出しの長押しで「タスクにする」「予定にする」「メモ帳に残す」。本文の中の日時（「来週火曜」「午後2時」など）を読んで入れます
  • 候補。取引先とのやり取りを AI が1通ずつ読み、相手からの依頼・自分がした約束・日時の決まった予定の候補を会話とタスクの画面に出します。既定は端末の中の AI（Apple Intelligence）で、メッセージは外へ送りません。利用者が自分の API キーを入れたときだけ、サーバーの AI（Anthropic・Google・OpenAI）で読む選択もあります。日付の計算は AI にさせず、アプリが行います
  • 期限が48時間以内になった候補を、自分の Gmail から自分宛てに1通にまとめて知らせる設定（オフが既定）
  • 新しいやり取りは、開いているあいだは即時に届き、ほかは5分ごとの取り込みで入ります。プッシュ通知はありません

メモ帳

  • 題名と本文だけのメモ。取引先か案件に結び付けられ、それぞれの詳細にも出ます
  • 題名・本文・取引先名・案件名で検索
  • メッセージの吹き出しから「メモ帳に残す」で本文を写して保存。メモからは「元の会話を開く」で元の1通に戻れます

ファイルと録音

  • 案件・予定・タスクに資料のファイル（画像・PDF・Word・Excel・PowerPoint・テキスト・CSV・ZIP。画像は10MB、ファイルは20MBまで）を付けて、その場で開けます
  • Mac では PDF と画像を拡大・縮小でき、別のウィンドウにも出せます。iPad では全画面で見られます
  • その場で録音して残せます（1回2時間まで。画面を消しても録り続け、電話が入ったら録れたぶんを残して止まります）
  • 録音の文字起こし（話の区切りごとに時刻の印）、要点の箇条書き、依頼・予定の候補の抜き出し。既定は端末の中で行い、音声は外へ出ません。利用者が選んだときだけ Gemini に文字起こしを頼めます
  • 文字起こしの時刻の印を押すと、その場所から再生します

レポート・CSV・ふるさと納税

  • 年を選んで、月ごとの売上・入金・経費・稼働と差引をグラフと表で見ます
  • CSV の書き出し（請求書・請求の明細・入金・支出・稼働・案件）。Excel やほかの会計ソフトで開けます
  • ふるさと納税の控除上限額の目安（2026年分までの決まりで計算）。売上や経費の出どころが揃うまで数字を出さず、迷うときは小さめに出します

freee との連携（つながなくても使えます）

  • freee からこのアプリへ帳簿を移した「切替日」を持ち、それより前は freee、以後はアプリの記録を正として年の数字を足します
  • 支出・請求書（会計の取引として、または freee請求書として）・見積書・ココナラの売上を、保存に連動して、または手で freee へ送ります。送ったあとに直したものは「変更あり」と分かります
  • 勘定科目・税区分・取引先の突き合わせ。非課税・免税の売上、事業主貸、家事按分（経費と私用分の2行）にも対応
  • freee請求書で番号を振ったときは、アプリの請求番号をそろえてから PDF を作ります

通知・ウィジェット・Siri

  • ホーム画面のウィジェット（月のカレンダー・これからの予定。iOS・Mac）と、ロック画面のウィジェット（今日の予定。iOS）
  • Siri と「ショートカット」から、今日のタスク・今日の予定・計測中の案件の読み上げと、画面を開く操作（「業務管理で今日の予定」など）
  • 通知は 予定・締切・納期・支払期限・タスクの期限・予約送信・月額の請求書の下書き。押すとその画面が開きます
  • iOS の共有シートと macOS の「サービス」から、見積書に起こす文章を受け取れます

見た目と使い勝手

  • 見た目を10案から選べます（標準・ミニマル・やわらか・グラス・帳場・ブロック・季節・計器盤・文房具・黒と金）。端末ごとの好みで、その場で切り替わります
  • ライト／ダークはシステムの外観に追従。取引先の色・土曜の青・プライベートの紫のように「色＝意味」のものは案で変わりません
  • どの画面からも読み直せます（iPhone・iPad は引っぱって更新、Mac は ⌘R）
  • iPhone Duo（折りたたみ）では、開くと案件とメッセージが2列になり、半分たたむと月のカレンダーや録音の画面を折り目で分けます。開閉しても開いていた画面は保たれます
  • 読み上げ（VoiceOver）で、色だけで出している意味（取引先・種類・既読・シークレット）を言葉で言います

データとサインイン

  • データは Supabase（Postgres・Storage）に、利用者ごとに分かれて保存します。請求書・明細・入金・支出・領収書の5つの帳簿は消しても履歴が残り（論理削除＋監査ログ）、電子帳簿保存法の訂正削除の履歴に対応します
  • サインインはメールのマジックリンク。届いたリンクを開くとアプリに戻ります
  • LINE・Chatwork の鍵は端末に残さず、Gmail の更新用のトークンは暗号化してサーバーに置きます（プライバシーポリシー）
  • サーバーに置いているファイルの量を、設定でいつでも確かめられます

まだ無いもの

  • Sign in with Apple（いまはメールのマジックリンクだけ）
  • オフラインでの利用（通信が無いあいだは読み書きできません）
  • メッセージのプッシュ通知（新着に気づくのは、開いているあいだと定期の取り込みです）
  • アプリの中からのアカウントの削除（画面は入っていますが、サーバー側の準備中です。削除のご希望はお問い合わせ先へ）
  • 一般への配布（App Store には出していません）
