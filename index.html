業務管理（GyomuKanri）

運営: unnamed　行方 浩太

業務管理（GyomuKanri）は、個人事業主が案件・支出・予定・請求書をひとつにまとめて管理するための iPhone / iPad / Mac のアプリです。現在は運営者本人が自分の業務のために使っています。

Google アカウントとの連携について

本アプリは、次の2つのために Google の Gmail API を使います。

  • 利用者が日時を指定して予約した請求書のメールを、利用者自身の Gmail から送る（「メールの送信」gmail.send）
  • 利用者が登録した取引先とのメールを取り込み、取引先ごとのやりとりとして表示する（「メールの閲覧」gmail.readonly。利用者が許可したときだけ）

メールを変更・削除することはありません。取引先として登録していないアドレスとのメールは取り込みません。

取得する情報と、その扱いは プライバシーポリシー に記載しています。
