unnamed　行方 浩太（以下「運営者」）は、iPhone / iPad / Mac 向けアプリ「業務管理（GyomuKanri）」 （以下「本アプリ」）における利用者の情報の扱いを、以下のとおり定めます。

1. 本アプリについて

本アプリは、個人事業主が案件・支出・予定・請求書を管理するためのアプリです。 現在は運営者本人が自分の業務のために使っており、一般には提供していません。

2. Google アカウントから取得する情報

本アプリは、利用者が Gmail との連携を許可したときに、次の情報を Google から受け取ります。

  • Google アカウントのメールアドレス（openid / email）… どの Gmail と連携しているかを画面に表示するため
  • Gmail でメールを送信する権限（https://www.googleapis.com/auth/gmail.send）… 下の3の目的のため
  • Gmail のメールを読む権限（https://www.googleapis.com/auth/gmail.readonly）… 下の3の目的のため。利用者が許可したときだけ

本アプリは、メールを変更する・削除する権限は求めません。連絡先・カレンダーなど、上記以外の Google の情報には アクセスしません。

3. 情報の利用目的

Gmail の送信権限は、利用者が本アプリで日時を指定して予約した請求書のメールを、 その日時に利用者の Gmail から送信するためだけに使います。送るメールの宛先・件名・本文・添付の 請求書 PDF は、利用者が本アプリで作成・確認したものです。送信の控えとして、同じメールを利用者自身にも BCC で送ります。

Gmail の読む権限は、利用者が本アプリに登録したメールアドレス（取引先のアドレスと、 「個人」の相手として登録したアドレス）が差出人・宛先・Cc のどれかに入っているメールだけを本アプリの「メッセージ」に取り込み、 相手ごとのやりとりとして表示するために使います。 登録したアドレスが1つも入っていないメールは取り込みません。本アプリから返信したメールは、 上の送信権限で利用者の Gmail から送ります。

4. 情報の保存と管理

  • Google から受け取った更新用のトークンは、AES-256-GCM で暗号化したうえで、本アプリの サーバー（Supabase）に保存します。利用者の端末やアプリの画面からは読めない場所に置き、 メールの送信のときだけサーバーの中で使います。
  • 連携した Gmail のメールアドレスは、連携の状態を表示するために保存します。
  • 予約したメールの添付 PDF は、送信が終わるまでサーバーに保存し、送信の処理が終わったあとに削除します。
  • 「メッセージ」に取り込んだメールは、件名・本文・送受信の日時・相手のアドレスを本アプリのサーバーに保存します。 受け取ったメールの添付ファイルの中身は保存しません。
  • 本アプリからメールで画像・動画・ファイルを送ると、そのファイルを本アプリのサーバー（Supabase Storage）に保存し、 利用者の Gmail から添付ファイルとして送ります。送ったメールと添付ファイルは相手のメールサーバーに残り、本アプリからは消せません。
  • 案件・請求書・支出などの業務データは、本アプリのサーバー（Supabase）に保存し、 利用者本人だけがアクセスできるように制限しています。

5. LINE 公式アカウント・Chatwork との連携

利用者が本アプリの設定で連携すると、取引先や個人の相手とのやりとりを本アプリの「メッセージ」にまとめて表示し、 本アプリから返信できるようになります。

  • LINE 公式アカウント: 利用者の公式アカウントに届いたメッセージ（本文・送信日時・相手の表示名と LINE のユーザー ID）を、LINE から本アプリのサーバーに受け取って保存します。画像・動画・スタンプ・ファイルの 中身はサーバーに保存せず、取り出すための手がかり（スタンプの番号や、画像・動画の取り出し先）だけを保存します。画像と動画は、利用者が本アプリの会話を開いて表示するときに、その都度 LINE から 取り寄せて利用者の端末に表示します（LINE 側で取り出せる期間を過ぎると表示できません）。スタンプの絵は、 利用者の端末が LINE の配信サーバーから直接読み込みます。スタンプの絵や、LINE 以外の配信元にある画像・動画を 端末が直接読み込むときは、通常のウェブ閲覧と同じく、端末の IP アドレスや読み込んだ時刻がその配信元に伝わります。 読み込んだ画像・動画は、本アプリを開いているあいだだけ端末のメモリに置き、端末の記憶装置には残しません （動画の再生には一時ファイルを使い、再生の画面を閉じると削除します。削除できないまま終了したときは、次に本アプリを開いたときに削除します）。本アプリから返信すると、利用者の公式アカウントから相手に送ります。 利用者が本アプリでその相手との会話を開いて読むと、相手の LINE に「既読」と表示されるよう LINE に知らせます。 そのために、LINE がメッセージごとに渡す既読用の符号を本アプリのサーバーに保存し、知らせ終えたら削除します （読まれないまま 90 日が過ぎた符号も削除します。LINE 公式アカウントの「チャット」の設定がオンのときだけ働きます）。
  • 本アプリから LINE で画像・動画・ファイルを送ると、そのファイルを本アプリのサーバー（Supabase Storage）に保存し、 LINE にはそのファイルを取り出すための URL（推測できない鍵のついた、長い期間有効な URL）を渡します。 PDF などのファイルは、ファイル名とダウンロードの URL を文で送ります。この URL を知っている人は、 やりとりを削除するまでそのファイルを開けます。LINE が相手に届けたぶんは、相手の LINE に残ります。
  • Chatwork: 利用者が参加しているルームのメッセージ（本文・送信日時・送信者名）を取り込んで保存します。 本アプリから返信すると、利用者の Chatwork アカウントからそのルームに送ります。
  • 連携に使うチャネルシークレット・アクセストークン・API トークンは、AES-256-GCM で暗号化して 本アプリのサーバーに保存し、メッセージの受け取り・取り込み・返信のときだけサーバーの中で使います。 利用者の端末には保存しません。
  • 連携を外すと、保存しているトークンを削除します。取り込んだやりとりは、利用者が消すまで残ります。
  • 利用者は、本アプリの「メッセージ」の一覧から、相手ごとのやりとり（メッセージとメモ）を削除できます。 削除すると、本アプリのサーバーからそのやりとりと、送った・受け取った画像やファイルの中身を削除し、LINE に渡した URL も開けなくなります。 相手の LINE・メールに届いたぶんは相手の側に残ります。Web チャットのやりとりは、相手のページからも消えます。 相手の登録（取引先への結び付けなど）は残ります。
  • 「シークレット」にしたチャットは、端末の Face ID・Touch ID・パスコードで鍵を開けるまで、本アプリの画面に 名前や内容を表示しません。これは端末の画面での鍵で、やりとりはほかのメッセージと同じく本アプリのサーバーに保存されます。

6. 予定の共有

利用者は、本アプリで「予定の共有」の URL を作ることができます。共有の URL を知っている人は、 利用者が本アプリに登録した予定の件名と日時を、カレンダーアプリまたは 共有されたスケジュールのページで見ることができます。

  • 共有するのは予定の件名と日時だけです。場所・メモ・取引先・案件・請求書などの情報は含みません。
  • 共有の URL には推測できない合言葉が含まれます。URL を渡す相手は利用者が決めます。
  • 利用者が共有をやめると、その URL では直ちに予定を見られなくなります。ただし、相手のカレンダーアプリに すでに取り込まれた予定は、そのアプリが次に更新するまで相手の側に残ることがあります。
  • 共有されたスケジュールのページは、アクセス解析や広告のための仕組みを使っていません。

7. Web チャット

利用者は、本アプリで取引先・案件・個人の相手ごとに「Web チャット」の URL を作り、相手に渡すことができます。 URL を受け取った人（以下「相手」）は、本アプリを入れずに、ブラウザのチャットのページで 利用者とやりとりできます。

  • 相手が入れた名前と、相手と利用者が送ったメッセージの本文・日時を本アプリのサーバーに保存し、利用者の本アプリに表示します。 相手が見られるのは、その URL でのやりとりだけです。利用者のほかのメッセージ・メモ・業務データは見えません。
  • 相手のページが新しいメッセージを読み込むと、利用者の本アプリにそのメッセージが「既読」と表示されます。 利用者が読んだメッセージも、相手のページに「既読」と表示されます。相手のページが最後に読み込んだ時刻は、利用者が確認できます。
  • URL には推測できない合言葉が含まれます。利用者が設定した場合は、さらに6桁の数字の合言葉を入れないと開けません。 数字の合言葉は、元に戻せない形（ハッシュ）でだけサーバーに保存します。合言葉を入れたブラウザには、30日間有効な入場券を ブラウザの保存領域に置きます。
  • 相手と利用者は、画像（10MB まで）とファイル（PDF・Word・Excel・PowerPoint・テキスト・CSV・ZIP。20MB まで）も送れます。 画像とファイルは、LINE の場合と違い、中身を本アプリのサーバー（Supabase Storage）に保存します。 相手のページや本アプリから送る写真は、送る前に縮小して描き直し、撮影した場所などの写真に含まれる情報を取り除きます（GIF と、相手のブラウザが読み取れない形式の画像は、そのまま送られます）。 保存した画像・ファイルを開くときは、その都度、数分だけ有効な URL を発行します。
  • 利用者が URL を止めると、その URL ではやりとりを見られなくなります。やりとりの記録（画像・ファイルを含む）は利用者の本アプリに残ります。
  • チャットのページとの通信の記録（IP アドレス・日時など）は、本アプリのサーバー（Supabase）とページの配信元（GitHub Pages）の 仕組みとして一定期間残ることがあります。チャットのページは、アクセス解析や広告のための仕組みを使っていません。

8. 第三者への提供

運営者は、Google・LINE・Chatwork から受け取った情報と、Web チャットの相手から受け取った情報を第三者に販売・提供・共有しません。広告の配信、利用者の分析、 AI・機械学習のモデルの学習には使いません。ただし、法令に基づく場合を除きます。

本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。

9. 連携の解除と情報の削除

  • 本アプリの設定の「Gmail を外す」で連携を解除すると、保存している更新用のトークンと連携の情報を サーバーから削除し、Google 側の許可も取り消します。
  • Google アカウントの サードパーティ製のアプリとサービス からも、いつでも許可を取り消せます。
  • Web チャットの相手が、自分の名前ややりとり（画像・ファイルを含む）の削除を希望する場合は、URL をくれた利用者か、下のお問い合わせ先までご連絡ください。
  • その他の情報の削除を希望する場合は、下のお問い合わせ先までご連絡ください。
